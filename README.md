# 🗄️ Advanced SQL Data Analysis & Querying Portfolio

A comprehensive collection of advanced SQL scripts and data manipulation queries demonstrating relational database management, complex aggregations, and advanced data analytics techniques.

## 📌 Project Overview
This repository highlights core and advanced SQL querying skills applied to relational databases, focusing on extracting actionable business insights, product performance, and sales metrics.

## 🛠️ Key SQL Concepts Demonstrated
- **Data Manipulation Language (DML):** Inserting and updating records (`INSERT`, `UPDATE`).
- **Advanced Filtering & Patterns:** Using `IN`, `LIKE`, and wildcard escaping (`ESCAPE`).
- **Aggregations & Grouping:** Grouping data with conditional filtering using `GROUP BY` and `HAVING`.
- **Window Functions & Ranking:** Advanced ranking and analytical functions including `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()`.
- **Subqueries:** Utilizing nested queries for advanced multi-level data filtering.
